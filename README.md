## What This Tool Does

- Export transaction data to CSV format
- Multi-chain support (Ethereum, BSC, Polygon, Solana)
- Customizable filters (date range, amount, type)
- Batch export for multiple addresses
- Transaction details including fees and status
- Token transfers and internal transactions
- Clean and structured CSV output
- Works on Windows 10 and Windows 11

Blockchain CSV Exporter is a professional tool for users and analysts who need to export blockchain transaction data to CSV for further analysis. It provides multi-chain support, powerful filtering and clean output formatting. This is a fully functional application with no limitations.
